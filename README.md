# Verdania Story Map

Read-only snapshot of the Echoes of Verdania story map, published with GitHub Pages so it can be embedded in the campaign hub.

- `index.html` — the map page (map image and pins built in)
- `verdania-map.jpg` — the Meridian League map
- `pins.json` — the pins in this snapshot

Pins are edited on the live map in Claude, then a fresh snapshot is pushed here.
